# Crontab 配置说明
# 用于定时运行 user_stats.py 脚本

# ============================================
# 安装步骤：
# ============================================
# 1. 修改 run_user_stats.sh 中的 PROJECT_DIR 路径为实际路径
# 2. 设置脚本执行权限：
#    chmod +x /path/to/ClubEngine/stats/run_user_stats.sh
# 3. 编辑 crontab：
#    crontab -e
# 4. 添加下面的定时任务配置
# 5. 保存并退出

# ============================================
# 定时任务配置（每 2 小时执行一次）
# ============================================
0 */2 * * * /path/to/ClubEngine/stats/run_user_stats.sh

# ============================================
# 其他可选的定时配置示例：
# ============================================

# 每天上午 9 点执行
# 0 9 * * * /path/to/ClubEngine/stats/run_user_stats.sh

# 每天上午 9 点和下午 6 点执行
# 0 9,18 * * * /path/to/ClubEngine/stats/run_user_stats.sh

# 每小时执行一次
# 0 * * * * /path/to/ClubEngine/stats/run_user_stats.sh

# 每 4 小时执行一次
# 0 */4 * * * /path/to/ClubEngine/stats/run_user_stats.sh

# 每周一上午 9 点执行
# 0 9 * * 1 /path/to/ClubEngine/stats/run_user_stats.sh

# 每天午夜执行
# 0 0 * * * /path/to/ClubEngine/stats/run_user_stats.sh

# ============================================
# Cron 时间格式说明：
# ============================================
# ┌───────────── 分钟 (0 - 59)
# │ ┌───────────── 小时 (0 - 23)
# │ │ ┌───────────── 日期 (1 - 31)
# │ │ │ ┌───────────── 月份 (1 - 12)
# │ │ │ │ ┌───────────── 星期 (0 - 7, 0 和 7 都表示周日)
# │ │ │ │ │
# * * * * * command

# ============================================
# 常用命令：
# ============================================
# 查看当前用户的定时任务
# crontab -l

# 编辑定时任务
# crontab -e

# 删除当前用户的所有定时任务
# crontab -r

# 查看定时任务执行日志
# tail -f /path/to/ClubEngine/logs/user_stats.log

# 查看系统 cron 日志 (不同系统路径可能不同)
# tail -f /var/log/cron
# 或
# tail -f /var/log/syslog | grep CRON

# ============================================
# 注意事项：
# ============================================
# 1. 将所有 /path/to/ClubEngine 替换为实际的项目绝对路径
# 2. 确保 Python 环境已安装所有依赖包 (pip install -r requirements.txt)
# 3. 如果使用虚拟环境，需要在 run_user_stats.sh 中取消注释并修改虚拟环境路径
# 4. 确保数据库连接配置正确
# 5. 确保脚本有执行权限 (chmod +x)
# 6. cron 任务的环境变量可能与交互式 shell 不同，建议在脚本中使用绝对路径
